# CSS Grid Layout — Basic to Advanced

A practical CSS Grid learning project covering concepts from basic to advanced level. This project includes grid containers, rows, columns, gaps, alignment, responsive layouts, grid areas, and real-world website layout practices.

## Topics Covered

* CSS Grid basics
* `display: grid`
* Rows and columns
* `grid-template-columns`
* `grid-template-rows`
* `gap`
* `grid-column` and `grid-row`
* `fr` unit
* `repeat()`
* `minmax()`
* `auto-fit` and `auto-fill`
* Grid alignment
* Named grid areas
* Responsive Grid layouts
* Real-world website layouts

## Goal
To build a strong understanding of CSS Grid by progressing from simple exercises to advanced and responsive real-world layouts.
